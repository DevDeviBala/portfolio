# Devi Bala M — Portfolio

Premium, dark-first software engineer portfolio built with Next.js 14 (App Router),
TypeScript, and Tailwind CSS.

## Stack

- **Next.js 14** — App Router, static generation, `next/font` for self-hosted fonts
- **TypeScript** — full type safety
- **Tailwind CSS** — tokenised design system
- **Zero runtime animation libraries** — CSS-only transitions + IntersectionObserver

## Getting Started

```bash
npm install
npm run dev
