Engineering Automation · Legacy System Integration

CAD / Kitchen Hood Drawing Generator

A Django-based engineering automation system that integrates with an existing PHP CRM and automatically generates manufacturing-ready CAD drawings from project specifications.

▾

Business Problem

Engineers previously had to manually enter project and hood specifications into the drawing workflow. The existing PHP CRM already contained the required project and customer information. The goal was to eliminate duplicate data entry and automate CAD drawing generation.

Architecture

PHP CRM │ │ Job ID / Job Name ▼ Django Application │ │ REST API ▼ Fetch Job Specifications │ ▼ Pre-filled Drawing Form │ ▼ Engineer Reviews / Adjusts │ ▼ Drawing Generation Engine │ ▼ DXF File │ ▼ AutoCAD / LibreCAD / DraftSight

Technical Implementation

DjangoPythonREST APIPHP CRM Integration Form ProcessingJSON Drawing ConfigDXF Generation ezdxfAutomated DimensionsPlan/Elevation/Section Drawing SchedulesCustom Components

Workflow

Sales enters project information ↓ Information stored in PHP CRM ↓ Engineer clicks "Generate Drawing" ↓ Django receives Job ID ↓ Django retrieves project information ↓ Drawing form is automatically populated ↓ Engineer reviews / modifies data ↓ Django generates DXF ↓ Engineer downloads manufacturing drawing

Key Engineering Decision

Why Django was not built as a replacement for the CRM: The CRM remained the source of truth. The Django application specialized in CAD generation. This separation avoided duplicating CRM functionality and allowed the drawing-generation logic to evolve independently.

Important Engineering Concepts

Webhook-driven architecture

External marketplace events trigger backend processing.

Asynchronous processing

Long-running or failure-prone operations are moved into background workers.

Retry handling

Temporary external API failures can be retried rather than immediately failing the entire workflow.

Exponential backoff

Retries are spaced progressively to avoid hammering external services.

Structured logging

Important workflow events and failures can be traced systematically.

Data Platform · Maritime Analytics · Regulatory Compliance

Marine Emission & Compliance Management Platform

A data-driven maritime platform used by shipping-industry organizations to process vessel and voyage data, calculate emissions, evaluate regulatory compliance, and visualize fleet and vessel performance.

▾

Business Domain

The platform receives vessel operational data from a reporting tool in Excel format. The data can contain vessel information, voyage information, machinery information, fuel consumption, operational measurements, and other reporting fields. The incoming data is processed and classified before being stored in MongoDB. The platform then performs emission calculations and compliance calculations across vessels and voyages.

Platform Architecture

SHIPPING OPERATIONS │ ▼ Reporting Tool │ ▼ Excel Data │ ▼ Azure Logic App │ Data Processing Classification │ ▼ MongoDB │ ┌─────────────┴─────────────┐ │ │ ▼ ▼ Emission Calculations Compliance Calculations │ │ │ ┌─────┼─────┐ │ │ │ │ │ EU UK IMO │ │ │ │ └──────────────┬──────┴─────┴─────┘ ▼ Backend / APIs │ ▼ Analytics Dashboard │ ┌──────────┼──────────┐ ▼ ▼ ▼ Fleet Vessel Voyage Level Level Level

Platform Features

1. Data Ingestion

Excel reporting data enters the platform. Azure Logic Apps process and classify the incoming information before it is stored in MongoDB.

2. Emission Calculation

The platform processes machinery and fuel-consumption information. Emission values are calculated for different gases using domain-specific standard formulas.

3. Regulatory Compliance

Calculates and presents compliance information for EU ETS, FuelEU, EU MRV, UK MRV, IMO / DCS, CII, UK ETS, and other compliance modules. These are compliance calculations — not certifications.

4. Fleet Dashboard

Company → Fleet → Vessel → Voyage. Provides fleet-level analytics, vessel-level analytics, voyage details, charts, graphs, filters, and comparative views.

5. Multi-Tenant Access

Platform Admin → Companies → Fleets → Vessels. Company managers manage users and data access for their organization. Users see data according to their organization/fleet access.

6. Reporting Tool Generator

Company users select required fields and generate a customized Excel macro-enabled reporting tool. Users enter data, which then flows back into the platform.

7. Compliance Data Export

Users select a compliance module and required data/format, then download an Excel report.
